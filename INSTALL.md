# Player setup

Follow the complete [player guide](release/m27/player-guide.md).
Supported: Windows 10, official Archipelago 0.6.8, supported complete BizHawk
2.10/NesHawk, owned clean SMB3 USA Rev A. Install only `smb3x.apworld` in this
separate AP installation. Historical `smb3.apworld` needs another installation.

Options Creator's full displayed game name is
**Super Mario Bros. 3: Expanded Multiworld**. Export a fresh default player YAML;
generation creates `.apsmb3x`. Open through the matching Launcher and keep the
file and whole managed folder for Resume. No standalone development tools are
needed by players. See [README](README.md) for music, saves and limitations.

M35 emulator/version and State boundaries are documented in
[emulator qualification](docs/emulator-qualification.md). Original project source
notices use MPL-2.0; see LICENSE-SCOPE.json and NOTICE.md for exclusions.
