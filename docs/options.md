# Options

Level Shuffle offers **Vanilla** (default), **Balanced**, and **Compatible**, in
that order. Vanilla retains original stage placement. Balanced shuffles the 53
certified original stages within the same or neighboring original worlds.
Compatible uses the entire technically eligible pool, including distant worlds;
it has no world-proximity or difficulty-band restriction. Both retain mandatory
entry, exit, routing, tileset and softlock protections. There is no separate range
or pool setting. Some technically uncertified stage entrances remain fixed.

Special Stage Shuffle can stay Off, shuffle By Type, or use reviewed Mixed
Fortresses. It requires Balanced or Compatible. Original palettes and Vanilla
level/world-map music remain the defaults; Atmospheric/Full palettes and independent
Shuffled original music are optional. Private soundtrack modes require a separately
bound private build and fail clearly in this public flavor.

World Pass Placement, Hammers, goals, Star Fragments, optional hazards/effects,
blessings and DeathLink keep their existing meanings. Regional Hammers are reusable;
Legacy Hammers are consumable. Minimal accessibility may need Unrestricted World
Pass Placement. Bowser is victory-only; the game has 125 reward locations.
