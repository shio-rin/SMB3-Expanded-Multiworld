# Beta distribution status

The first SMB3X beta is being staged in the owner's **Private** GitHub repository.
Its release must remain an **unpublished draft** pending separate owner review and
authorization. No public distribution is authorized by the current instruction.

M36 passed independent technical verification and its membership evidence was
corrected without changing the package. The three native copyright uncertainties
remain documented; no legal clearance is claimed. See the current
[licensing addendum](beta/licensing.md), [provenance](beta/provenance.md),
[release notes](beta/release-notes.md) and [installation guide](beta/player-guide.md).

The exact M36 package and all recipe inputs stay unchanged. Package-bound guides
and notices retain historical wording to preserve reproduction. The current beta
guides supply the corrected installation, supported versions and coexistence
instructions. Original ROMs, local prepared ROM/BPS, States, private music, sessions
and private evidence never belong in a release.
