# Contributing

Bug reports, suggestions and playthrough feedback are useful contributions.
[Open an issue](https://github.com/shio-rin/SMB3-Expanded-Multiworld/issues) and tell
us what happened or what you'd like to improve. You don't need a diagnosis or
reliable reproduction steps. Screenshots and error messages can help.

Documentation fixes and code improvements are welcome too. Discuss larger changes
in an issue before investing substantial effort. For a pull request, briefly
explain the change and how you checked it. Be honest about what you haven't tested;
a typo fix doesn't need gameplay testing.

Code contributors can start with [Development](DEVELOPMENT.md) and the
[Codebase guide](CODEBASE_GUIDE.md). [Testing](TESTING.md) helps you choose checks
for the behavior you're changing.

Contributions must be yours to license under MPL-2.0 or have appropriate compatible
terms and notices; see [licensing scope and exceptions](docs/beta/licensing.md).
Keep ROMs, saves and credentials out of issues and commits. See
[reporting help](docs/beta/troubleshooting.md#report-a-bug) if needed.
